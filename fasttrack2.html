🔗 Google Fit Setup

Xiaomi Scale 2 → Zepp Life → Google Fit → FastTrack. One-time setup takes ~5 min.

1.Go to console.cloud.google.com → New project → name it "FastTrack"
2.Search "Fitness API" → Enable it
3.Credentials → Create → OAuth 2.0 Client ID → Web application
4.Authorized JS origins: add your app URL (e.g. https://yourname.github.io)
5.Copy the Client ID into FastTrack's Google Fit section
💡 Also make sure Zepp Life is connected to Google Fit:
Zepp Life → Profile → Connected apps → Google Fit → Enable
